# ⚔ Врата Бальдура — WebGPU прототип (фулстек)

Браузерная CRPG-прототип в духе **Baldur's Gate 3** на **Three.js 0.180 WebGPU**
(автоматический фоллбек на WebGL2) с полноценной **fullstack-структурой Next.js 16**.

**Версия v2.1 «Аура бездны»** — **босс-механики арены, стела рекордов и честная таблица глубины**. **Чемпион бездны** теперь настоящая
мини-босс-фигура: **аура бездны** — враги в 2 клетках от живого чемпиона бьют на +2 сильнее (герои не бустятся); **«БЕЗДНА ЗОВЁТ»** —
на полсмерти чемпион раз за бой поднимает двух глубинных утопленников (в бой, в инициативу и в combatGroup — чинит латентный баг
подкреплений v0.8/v1.8, когда вызовы не блокировали победу по checkEnd). **Стела рекордов** — интеракт у портала цитадели: журнал
завершённых и сорванных заходов (последние 8 в сейве, опциональное поле v2 — формат не сломан), лучший заход и даты. Срыв ухода
с карты тоже пишется в журнал (teardown зовёт bus.arenaBreak — без циклов). **Балансовая таблица глубины** зафиксирована и
дополнена: hp ×(1+0.12k) · кость урона +⌊k/2⌋ · **КД +min(⌊k/4⌋,2)** — пробитие сохраняется на глубине. Гонка v2.0 устранена:
повторный вход в портал в окне таймера волны больше не сносит новый заход (счётчик G.arenaRun убивает старые таймеры).
**Предыдущая v2.0 «Бесконечное испытание»** — **арена без дна**. Когда «Испытание Глубин» пройдено (рекорд ≥5 волн), портал за спиной
коменданта меняет лик: теперь это **БЕСКОНЕЧНОЕ ИСПЫТАНИЕ** — волны 6, 7, 8… продолжаются, пока стоит отряд (или пока отряд не
уйдёт с карты — испытание срывается). Глубина k=w−5 усиливает тени: hp ×(1+0.12k), кость урона +⌊k/2⌋, имена с приставкой
«Глубинный»; составы волн циклятся по 5 рецептам (прилив теней / хор глубин / стражи костей / клеймо бездны / ярость толпы),
а каждый 5-й глубинной волны (10-я, 15-я…) приводит **Чемпиона бездны** — элитного вожака с двойной наградой. Награда за волну
растёт с глубиной: 40+15·w+10·(w−5). Рекорд (S.arenaBest) по-прежнему пишется в сейв v2 (обратная совместимость — формат не
менялся), и вернувшемуся игроку портал сразу открывает бесконечный режим. Вместе с тем — **выравнивание @types/three до
~0.180** (убран разрыв версий типов 0.186 ↔ рантайм 0.180; tsc чист). **Предыдущая v1.9 «Слава Дозора»** — **постгейм после финала**. После гибели Малвеха у цитадели открываются три новых
возможности. **Шестой спутник — паладин Хальдир, Капитан Дозора** (молот 1d10+СИЛ, пластинчатый доспех, КД 16; карающий
удар 2d6+МДР излучения по ячейке, аура дозора +2 КД, наложение рук 1d8+2 — 1/бой; клятва держит страх) — стоит у знамён
за воротами и присоединяется по диалогу; восстанавливается при загрузке сейва (флаг haldirJoined). **Арена «Испытание
Глубин»** — повторяемые **пять волн теней павших** у изумрудного портала (утопленники → кости → песнь глубин → стена
щитов → гнев бездны), за каждую волну золото и перевязка, за всё испытание — награда коменданта; рекорд волн
(S.arenaBest) попадает в сейв v2 (опциональные поля, обратно совместимы). **Миникарта (M или 🗺)** — canvas-схема
сетки 28×28 в HUD: стены, отряд, враги, бочки, огонь, интерактивные точки, рамка текущего героя; обновляется
троттлингом 0.5 с из снимка стора (React-canvas). **Мотивы карт** — короткий звуковой стаер прибытия на каждую
локацию (WebAudio, без ассетов). **Предыдущая v1.8 «Цитадель Долгого Дозора»** — **финал кампании: пятая карта** (крепостная
стена с воротами, дворы цитадели, лорд-комендант Малвех с «Гласом глубин», гарнизон Глубинного — рыцари-отступники/адепт/
культисты, спецэкран «ДОЛГОЙ ДОЗОР!», сундук со Знаменем Дозора (+2 КД), фиксы латентных 404-багов v1.6). **Предыдущая v1.7 «Хореография битвы»** — **полная анимационная система на скелетных клипах Unity**. Из загруженных
Asset Store-пакетов (Blink «FREE — 32 RPG Animations», DoubleL RPG Animations) офлайн-пайплайн `scripts/bake_motions.mjs`
ретаргетит 12 движений на mixamorig-скелет Soldier (офлайн `SkeletonUtils.retargetClip`, маска костей AdvancedSkeleton/UE4→mixamo,
масштаб бедра по отношению рест-высот) и запекает `public/models/rig/motions.glb` (~1.3 МБ). Роли: idle/idleCombat (боевая
стойка в бою), walk/run, атаки по классу (воин 1H, великаны/огры 2H, маги/жрецы/друиды каст, плут и гоблины панчи),
реакция на урон (GetHit), смерть (клип доигрывает и замирает лежащим — процедурное падение капсул осталось фолбэком).
Модуль `motion.ts` — лист-библиотека клипов; `animation.ts` — стейт-машина (кроссфейды, одноразовые клипы, приоритет
атака>урон); хуки: `doAttack`→playAttack, `damageUnit`→playHit, `die`→playDeath, касты→каст-клип. Фолбэки: без
motions.glb — родные Idle/Walk/Run Soldier + процедурные «дыхание»/замах. E2E: `__bg3.animStats`, `loopStop/loopStart`,
`step` (боевое перемещение), `cam/ctl`. **Предыдущая v1.6 «Перевал великанов»** — четвёртая карта: северо-западнее тракта, за болотами, тропа ведёт в горную
расщелину, где огры во главе с великаном **Гаррумом Камнегрызом** (64 HP, швыряет валуны 2d6 на 6 клеток, на
полсмерти каменеет: «ГОРЫ ДРОЖАТ», КД +3; оползень — каменный град всем соседям) перекрыли дорогу к цитадели
Долгого Дозора; обрыв с мостом (единственный проход), огрский лагерь с сундуком (секира перевала 1d10+СИЛ),
квест «Перевал великанов» с наградой «Каменное сердце» (талисман +5 HP). Вместе с тем — **снаряжение/инвентарь
с эффектами**: сумка отряда и слоты героев (оружие/доспех/талисман) с аддитивными бонусами, панель «Снаряжение»
(I или 🎒), предметы падают из сундука, лавки Дамрока (Чешуя великана +2 КД, Кольцо дозорного +1 КД) и наград;
сейв v2 расширен опциональными bag/heroes[].gear. И — **ассеты POLYGON Nature (Synty)**: горы-периметр, сосны,
валуны, пещера, кости и черепа лагеря — FBX + общий палитровый атлас, загрузчик `world/nature.ts` (кэш + нормализация
материалов под WebGPU); плюс **атак-анимации**: doAttack играет Mixamo-клип, если положить GLB в `public/models/rig/attack.glb`
(скелет mixamorig), иначе — процедурный замах корпуса. Ранее в v1.5: третья карта (болота культистов), друид
**Ольха Тисовая** и серверные скрижали (Prisma/SQLite); в v1.4: обучение «Наставник» и облачные скрижали
(IndexedDB); в v1.3: спеллкастеры крипты, элитные мобы и лут-таблицы; в v1.2: партия из четырёх героев —
Илва (плут) и Кая (жрица); в v1.1: 3 слота сохранений с экспортом/импортом JSON и настройки графики; в v0.8:
вторая карта-подземелье, босс-некромант с фазами, боссбар; в v0.7: модульный `src/game/`, процедурный звук,
партиклы, glow-хала, слоумо-криты, GLTF/Mixamo-анимации и bloom-пасс (TSL PostProcessing).

## 🚀 Запуск

```bash
bun install
bun run dev        # → http://localhost:3000
```

Браузер: Chrome/Edge 113+ (WebGPU); в остальных — автоматический WebGL2-фоллбек.

## 🗂 Структура

После рефакторинга (REFACTORING.md, фазы 0–6) движок — оркестратор на ~300 строк,
игровые системы разложены по слоям; граф зависимостей ацикличен (проверка
`node scripts/cycles.js` → `NO CYCLES`), строгий TS (`noImplicitAny`, `allowJs:false`),
без `any`. Связь «вверх по слою» — через шину поздних связей `bus.ts`;
HUD — React-компоненты на zustand-сторе (Фаза 6), движок пишет view-модели в стор.

### Куда класть новый код (вклад разработчика)

- **Новая игровая система** (класс, статус, механика боя) → модуль в `systems/`, импорты
  только вниз (`state/types/constants/rng/utils` и другие системы ниже по слою). Вызов UI —
  через `bus.*.call()`, прямые импорты `ui/` из `systems/` запрещены (циклы).
- **Новый контент карты** → `world/props.ts` (декор) / `world/maps.ts` (сборка) / `interact/explore.ts` (интеракты).
- **Новый UI-элемент** → view-модель в `ui/store.ts` + React-компонент в `src/components/hud/`
  (компоненты НЕ импортируют движковые модули — только стор; вызовы в движок — через
  колбэки в view-моделях, биндят владельцы при загрузке модулей). Покадровые/3D-привязанные
  слои (полоски HP над головами, тултипы проекции) — императивно в `ui/`, реестр слоёв — `hud.ts`.
  Если система должна дёргать UI — слот в `bus.ts` + `bind` в владельце.
- **Новый доменный тип** → только `types.ts` (дубли типов запрещены); `any` запрещён
  (ESLint warn), непустые проверки `!` — только для DOM-реестра.
- **Сейвы** — формат v2 заморожен: новые поля героя/флагов добавляются опциональными
  (`?:`) и восстанавливаются дефолтами в `applyGame`; `SAVE_VER` не менять.
- Дисциплина: коммит+тег на фазу рефакторинга, E2E-гейт (`REFACTORING.md §5`),
  лимит размера модуля ≤ 400 строк.

## 🎮 Управление

| Ввод | Действие |
|---|---|
| **ЛКМ** по земле | идти отрядом (A*) / в бою — в пределах шагов |
| **ЛКМ** по врагу | диалог (первая встреча) или атака/заклинание |
| **E** у НПС / клик по НПС | диалог (торговец, пленная, патруль) |
| **J** | журнал заданий |
| **C** / клик по карточке | лист персонажа |
| **K** / 💾 | сохранения: 3 слота, экспорт/импорт JSON |
| **G** / ⚙ | настройки графики |
| **Z** | зоны угрозы |
| **🔊** (слева сверху) | звук вкл/выкл |
| **Пробел / кнопка** | завершить ход |

## 📦 Механики (v0.3 → v0.7)

- **v0.3 Тактика:** экономика действий, атаки по случаю (AoO), % попадания в тултипе, статусы (Горение/Отравление/Благословение/Страх)
- **v0.4 ИИ:** A*-навигация 28×28, Utility-ИИ гоблинов (фокус на раненых, кайт, выстрел по бочке), взрывные бочки с цепной детонацией, распространение огня по траве
- **v0.5 Персонажи:** классы (Воин/Волшебница), уровни/XP, 6 характеристик, ячейки заклинаний, лист персонажа
- **v0.6 Слова и золото:** диалоги с проверками d20+ХАР (убеждение/запугивание), квесты (журнал + трекер), торговец (7 товаров, скидка через ХАР), золото и лут, освобождение пленницы

## 🛠 Технологии

Next.js 16 (App Router, Turbopack) · TypeScript strict (`noImplicitAny`, `allowJs:false`, без `any`) ·
three@0.180 + `@types/three@~0.180` (выровнены в v2.0; `three/webgpu` + addons) · zustand (React-HUD) · IndexedDB (облачные скрижали) +
Prisma/SQLite (серверные скрижали, `/api/tablets`) · WebAudio API ·
модульный движок-оркестратор (`engine.ts` ~300 строк + 26 игровых модулей, ацикличный граф зависимостей) —
совместим с React-циклом монтирования (dispose→resetState).
