# ⚔ Врата Бальдура — WebGPU прототип (фулстек)

Браузерная CRPG-прототип в духе **Baldur's Gate 3** на **Three.js 0.180 WebGPU**
(автоматический фоллбек на WebGL2) с полноценной **fullstack-структурой Next.js 16**.

**Версия v1.3 «Слуги Костепёра»** — гарнизон крипты пополнили **спеллкастеры** (культисты с некротическим
сгустком и элитный ученик-целитель, латает слуг могильной песнью), враги получили **элитные версии**
(гоблин-ветеран в лагере, скелет-рыцарь у трона — крупнее, с золотым кольцом и реликвией в луте) и
**лут-таблицы** — добыча (золото/зелья/масло/реликвии) выпадает из каждого врага по его типу. Ранее в
v1.2: партия из четырёх героев — освобождённая Илва (плут) и жрица Кая (новый NPC у придорожного алтаря)
становятся играбельными спутницами с уникальными умениями классов. Ранее в v1.1: 3 слота сохранений с
экспортом/импортом JSON и панель настроек графики; в v0.8: вторая карта-подземелье, босс-некромант с
фазами, боссбар и переходы между картами; в v0.7: модульный `src/game/`, процедурный звук, партиклы,
glow-хала, слоумо-криты, **GLTF/Mixamo-анимации** (скелетные риги героев и босса) и **bloom-пасс**
(TSL PostProcessing).

## 🚀 Запуск

```bash
bun install
bun run dev        # → http://localhost:3000
```

Браузер: Chrome/Edge 113+ (WebGPU); в остальных — автоматический WebGL2-фоллбек.

## 🗂 Структура

```
src/
  app/
    page.tsx            # страница игры (динамический импорт клиента)
    layout.tsx          # метаданные v1.3
  components/
    GameClient.tsx      # React-обёртка: HUD + boot/dispose движка
  game/
    engine.js           # игровой движок (v0.6-фичи + v0.7/v0.8 + v1.1 сейвы/графика + v1.2 партия + v1.3 элита/лут)
    hud.ts              # разметка HUD (инжектится до старта движка)
    game.css            # стили HUD + v0.7/v0.8 + v1.1 (панели) + v1.2 (кнопки плута/жрицы)
    audio.ts            # v0.7: процедурный WebAudio SFX (без ассетов)
    particles.ts        # v0.7: пул партиклов (искры, угли, взрывы, лечение)
    glow.ts             # v0.7: glow-хала (bloom-lite): костёр, плиты огня, вспышки
    slowmo.ts           # v0.7: слоумо-криты (time scale + виньетка)
    animation.ts        # v0.7.x: GLTF/Mixamo-риг (Idle/Walk/Run, SkeletonUtils,
                        #   AnimationMixer, кроссфейды, фоллбек на капсулы) + bloom-инфра
public/
  legacy/
    bg3-prototype-v0.5.html   # архивная однофайловая сборка v0.5 (страница /legacy/...)
    bg3-prototype-v0.6.html   # архивная однофайловая сборка v0.6
```

## 🎮 Управление

| Ввод | Действие |
|---|---|
| **ЛКМ** по земле | идти отрядом (A*) / в бою — в пределах шагов |
| **ЛКМ** по врагу | диалог (первая встреча) или атака/заклинание |
| **E** у НПС / клик по НПС | диалог (торговец, пленная, патруль) |
| **J** | журнал заданий |
| **C** / клик по карточке | лист персонажа |
| **K** / 💾 | сохранения: 3 слота, экспорт/импорт JSON |
| **G** / ⚙ | настройки графики |
| **Z** | зоны угрозы |
| **🔊** (слева сверху) | звук вкл/выкл |
| **Пробел / кнопка** | завершить ход |

## 📦 Механики (v0.3 → v0.7)

- **v0.3 Тактика:** экономика действий, атаки по случаю (AoO), % попадания в тултипе, статусы (Горение/Отравление/Благословение/Страх)
- **v0.4 ИИ:** A*-навигация 28×28, Utility-ИИ гоблинов (фокус на раненых, кайт, выстрел по бочке), взрывные бочки с цепной детонацией, распространение огня по траве
- **v0.5 Персонажи:** классы (Воин/Волшебница), уровни/XP, 6 характеристик, ячейки заклинаний, лист персонажа
- **v0.6 Слова и золото:** диалоги с проверками d20+ХАР (убеждение/запугивание), квесты (журнал + трекер), торговец (7 товаров, скидка через ХАР), золото и лут, освобождение пленницы
- **v0.7 Слово и сталь:** процедурный WebAudio-звук (удары/криты/магия/взрывы/фанфары/стингеры боя и победы + фоновый ветер), пул партиклов на THREE.Points (искры ударов, угли костра и плит огня, золотые взрывы уровней, кровавые всплески), glow-хала вместо тяжёлого bloom, слоумо-криты с виньеткой (time scale замедляет все твины), кнопка мьюта
- **v0.7.x Анимации и bloom:** скелетные GLTF-риг (Soldier.glb, Mixamo-стайл) для героев и босса через SkeletonUtils.clone + AnimationMixer (Idle/Walk/Run с кроссфейдами; подкраска фракций, фоллбек на капсулы при недоступности CDN), выпад корпусом при атаке, полный bloom-пасс через TSL PostProcessing (работает и на WebGL2-бэкенде, при сбое — автооткат на обычный рендер), замедление анимаций в слоумо
- **v0.8 Крипта Костепёра:** система карт (лес ↔ крипта: seed-функции сетки, worldGroup, фейд-переход с параметрическим светом/туманом/атмосферой), подземелье с пилястрами, саркофагами, зелёными жаровнями и троном; босс Вхорил Костепёр (46 HP, жезл гнили 1d8+ИНТ с ядом, Костяной шквал 2d6 некротического всем соседям, иммунитет к страху, фаза 2 на 50% HP — призыв 2 скелетов в бой); скелеты-стражи; боссбар с живым HP; новый квест «Сердце крипты» + подсказки Дамрока; сундук за печатью (золото, зелья, перстень +1 КД); урны-аналоги бочек; герои, прогресс, флаги и квесты переживают смену карт
- **v1.1 Скрижали судьбы:** сохранения в **3 слота** (localStorage, формат JSON v2: карта, золото, скидка, флаги мира, квесты, герои с инвентарём/уровнями/характеристиками и позициями); экспорт слота в скачиваемый JSON-файл и импорт обратно с валидацией; загрузка с экрана поражения (отряд «приходит в себя» с 1+ HP); убитые боссы не возрождаются после загрузки (флаг necroSlain); **панель настроек графики** (⚙ / G): тени (выкл/1024/2048), bloom-пасс, glow-хала, плотность частиц (40/70/100%), масштаб разрешения (50/75/100%), лимит FPS (30/60/без) + пресеты Низкий/Средний/Высокий — всё применяется на живую и сохраняется в localStorage
- **v1.2 Отряд Долгого Дозора:** **партия из четырёх героев** — освобождённая Илва (плут: короткий лук 1d6+ЛОВ, Подлый удар +1d6/2d6 во фланге, Отравленный клинок, Уклонение КД+3, уровни с ЛОВ) присоединяется после освобождения, жрица **Кая Заря** (булава, Лечение 1d8+МДР, Щит веры +2 КД, Карание света 2d6 излучения, **Гнев рассвета** 1/бой — ×2 против нежити, ячейки заклинаний как у волшебницы) ждёт у нового придорожного алтаря (диалог с лором кургана); флаги ilvaFreed/kayaJoined попадают в сейвы (format v2 сохранён — старые сейвы v1.1 совместимы, спутники восстанавливаются через ensureCompanions); GLTF-риги и тинты для спутников; баланс: +1 гоблин в лагере, +1 скелет в крипте; новые статусы Уклонение/Щит веры влияют на ИИ (гоблины реже попадают)
- **v1.3 Слуги Костепёра:** **спеллкастеры крипты** — культисты Костепёра (некротический сгусток 1d6+ИНТ, дальность 7, яд) и элитный **ученик-целитель** (луч могильного холода 1d8+ИНТ; ИИ: первым делом латает раненых слуг могильной песнью 2d4+ИНТ, тултип-подсказка «бейте первым»); **элитные мобы** — общий «класс элиты» (масштаб ×1.16, золотое кольцо Initiative, флаг в тултипе «· ЭЛИТА»): гоблин-ветеран с двуручным тесаком 1d10 в лагере и скелет-рыцарь с клеймором 1d8 у трона; **лут-таблицы** — из каждого врага выпадает добыча по типу (гоблины/нежить/культисты/боссы: золото, шанс зелья и огненного масла), элита даёт ×2 золота + гарантированный предмет + **реликвию** (Костяной оберег +1 КД, Пыльный фолиант +1 ячейка, Трофейный клык +1 СИЛ; одна на героя, поле relic в сейвах v2); баланс: гарнизон крипты 6+босс, лагерь 6+вожак
