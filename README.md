# ⚔ BG3 WebGPU Prototype — v0.6 «Слова и золото»

Однофайловый браузерный прототип **Baldur's Gate 3** на **Three.js 0.180 (WebGPURenderer, автоматический фоллбек на WebGL2)**: изометрическая ARPG-арена с пошаговыми боями по мотивам **D&D 5e (d20)**, диалогами с проверками Харизмы, квестами и торговцем.

## 🚀 Запуск

Вариант 1 — просто открыть `index.html` двойным кликом (модули Three.js тянутся с CDN — нужен интернет).

Вариант 2 — надёжнее, через локальный сервер:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

Браузер: Chrome/Edge 113+ (WebGPU) — включится GPU-путь; в старых браузерах автоматический фоллбек на WebGL2.

## 🎮 Управление

| Ввод | Действие |
|---|---|
| **ЛКМ** по земле | идти (A*-поиск пути) / двигаться в бою (в пределах шагов) |
| **ЛКМ** по гоблину | диалог (первая встреча) или атака/заклинание |
| **E** рядом с НПС | диалог (торговец, пленная, патруль) |
| **ЛКМ по кнопке умения** | выбрать цель → ЛКМ по цели |
| **ПКМ-драг / колесо** | орбита камеры / зум |
| **C / J / I / L** | персонаж / задания / инвентарь / хроника |
| **Z** | показать зоны угрозы (AoO-радиусы, огонь) |
| **Пробел** | завершить ход |

## 📦 Что реализовано

**v0.3 — Тактика:** экономика действий (Действие / Бонус / Реакция / Перемещение в метрах), атаки по случаю (AoO) при выходе из зоны угрозы, тултипы с % попадания, статусы (Горение, Отравление, Благословение, Страх) с иконками над головой.

**v0.4 — ИИ и разрушения:** A*-навигация по сетке 28×28 (запрет среза углов), Utility-ИИ гоблинов (концентрация на раненых, кайтинг шамана, выстрел по бочке, отход), взрывные бочки с цепной детонацией, распространение огня по траве, опасные зоны.

**v0.5 — Персонажи:** классы (Воин / Волшебница / Жрец), уровни и опыт, шесть характеристик (СИЛ/ЛОВ/ТЕЛ/ИНТ/МУД/ХАР) с модификаторами, оружие и доспехи (КД и урон), лист персонажа.

**v0.6 — Слова и золото:** диалоговый движок с ветвлениями и социальными проверками **d20 + ХАР** (убеждение/запугивание — патруль можно прогнать словами, вожака Грата — запугать, торговца Дамрока — сторговать скидку), мирный режим исследования карты, система квестов (журнал + трекер: «Кости и пепел», «Свободу разведчице», «Похищенный товар»), лавка торговца (7 товаров: зелья, огненное масло, щит/амулет, лук, кольчуга), золото и лут с гоблинов.

## 🛠 Технологии

Three.js 0.180 (`WebGPURenderer` + importmap CDN jsdelivr) · OrbitControls · raycasting (выбор целей, % попадания) · собственный движок d20 (инициатива, КД, криты 20/1, спасброски) · A* · Utility AI · один HTML-файл без сборки.
