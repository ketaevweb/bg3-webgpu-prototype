# ⚔ Врата Бальдура — WebGPU прототип (фулстек)

Браузерная CRPG-прототип в духе **Baldur's Gate 3** на **Three.js 0.180 WebGPU**
(автоматический фоллбек на WebGL2) с полноценной **fullstack-структурой Next.js 16**.

**Версия v1.5 «Болота культистов»** — **третья карта**: восточнее тракта, за криптой, гать тонет в
трясину, где культисты Глубинного во главе с жрицей **Ульвой, Матерью Топей** (54 HP, хлыст трясины
с ядом, на полсмерти поднимает утопленников из жижи) будят тину; новые враги — утопленники и культисты
Глубин, непроходимая трясина, камыш и лужи стоячей воды, идол Глубинного с зелёным пламенем; квест
«Шёпот глубин» с реликвией-наградой «Болотный жемчуг» (+1 МДР). Вместе с тем — **пятый класс**: друид
**Ольха Тисовая** (прикована культистами к идолу; Разряд молнии 2d6+МДР и Облако спор — ядовитая завеса
без дружественного огня) становится пятой играбельной спутницей; и **серверные скрижали**: каждый сейв
зеркалится на сервер (Prisma/SQLite, API-роут `/api/tablets`) — кампания переживает не только очистку
браузера (IndexedDB, v1.4), но и смену машины; в панели сейвов — кнопки «На сервер»/«С сервера» и метка
«⇅ на сервере». Ранее в v1.4: пошаговое обучение «Наставник» и облачные скрижали (IndexedDB), багфикс ИИ
дальнего сближения; в v1.3: спеллкастеры крипты, элитные мобы и лут-таблицы; в v1.2: партия из четырёх
героев — Илва (плут) и Кая (жрица); в v1.1: 3 слота сохранений с экспортом/импортом JSON и настройки
графики; в v0.8: вторая карта-подземелье, босс-некромант с фазами, боссбар; в v0.7: модульный `src/game/`,
процедурный звук, партиклы, glow-хала, слоумо-криты, GLTF/Mixamo-анимации и bloom-пасс (TSL PostProcessing).

## 🚀 Запуск

```bash
bun install
bun run dev        # → http://localhost:3000
```

Браузер: Chrome/Edge 113+ (WebGPU); в остальных — автоматический WebGL2-фоллбек.

## 🗂 Структура

После рефакторинга (REFACTORING.md, фазы 0–6) движок — оркестратор на ~300 строк,
игровые системы разложены по слоям; граф зависимостей ацикличен (проверка
`node scripts/cycles.js` → `NO CYCLES`), строгий TS (`noImplicitAny`, `allowJs:false`),
без `any`. Связь «вверх по слою» — через шину поздних связей `bus.ts`;
HUD — React-компоненты на zustand-сторе (Фаза 6), движок пишет view-модели в стор.

### Куда класть новый код (вклад разработчика)

- **Новая игровая система** (класс, статус, механика боя) → модуль в `systems/`, импорты
  только вниз (`state/types/constants/rng/utils` и другие системы ниже по слою). Вызов UI —
  через `bus.*.call()`, прямые импорты `ui/` из `systems/` запрещены (циклы).
- **Новый контент карты** → `world/props.ts` (декор) / `world/maps.ts` (сборка) / `interact/explore.ts` (интеракты).
- **Новый UI-элемент** → view-модель в `ui/store.ts` + React-компонент в `src/components/hud/`
  (компоненты НЕ импортируют движковые модули — только стор; вызовы в движок — через
  колбэки в view-моделях, биндят владельцы при загрузке модулей). Покадровые/3D-привязанные
  слои (полоски HP над головами, тултипы проекции) — императивно в `ui/`, реестр слоёв — `hud.ts`.
  Если система должна дёргать UI — слот в `bus.ts` + `bind` в владельце.
- **Новый доменный тип** → только `types.ts` (дубли типов запрещены); `any` запрещён
  (ESLint warn), непустые проверки `!` — только для DOM-реестра.
- **Сейвы** — формат v2 заморожен: новые поля героя/флагов добавляются опциональными
  (`?:`) и восстанавливаются дефолтами в `applyGame`; `SAVE_VER` не менять.
- Дисциплина: коммит+тег на фазу рефакторинга, E2E-гейт (`REFACTORING.md §5`),
  лимит размера модуля ≤ 400 строк.

## 🎮 Управление

| Ввод | Действие |
|---|---|
| **ЛКМ** по земле | идти отрядом (A*) / в бою — в пределах шагов |
| **ЛКМ** по врагу | диалог (первая встреча) или атака/заклинание |
| **E** у НПС / клик по НПС | диалог (торговец, пленная, патруль) |
| **J** | журнал заданий |
| **C** / клик по карточке | лист персонажа |
| **K** / 💾 | сохранения: 3 слота, экспорт/импорт JSON |
| **G** / ⚙ | настройки графики |
| **Z** | зоны угрозы |
| **🔊** (слева сверху) | звук вкл/выкл |
| **Пробел / кнопка** | завершить ход |

## 🛠 Технологии

Next.js 16 (App Router, Turbopack) · TypeScript strict (`noImplicitAny`, `allowJs:false`, без `any`) ·
three@0.180 (`three/webgpu` + addons) · zustand (React-HUD) · IndexedDB (облачные скрижали) +
